# Django Todo App 🚀

A beginner-friendly Todo App built with Django.

## ✨ Features

* Add Tasks
* Update Tasks
* Delete Tasks
* Search Tasks
* Mark Tasks as Completed
* Responsive Bootstrap UI
* Django Admin Panel

## 🛠 Tech Stack

* Python
* Django
* HTML
* CSS
* Bootstrap
* SQLite

## 📚 What I Learned

* Django Models
* CRUD Operations
* Templates & URLs
* Database Handling
* Frontend + Backend Integration

## ▶️ Run Project

```bash
python manage.py runserver
```
